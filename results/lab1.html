STEP 3 — 정답지를 치우고, 공정하게 나눕니다¶

TWF·HDF·PWF·OSF·RNF 는 고장이 난 뒤에 기록된 원인 표시입니다. 예측하는 시점에는 알 수 없는 값이므로 입력에서 뺍니다. 넣어 두면 정답지를 보고 시험을 치는 셈이 됩니다. 제안서를 볼 때도 같은 질문을 씁니다 — "그 값, 예측하는 시점에 알 수 있습니까?"

from sklearn.model_selection import train_test_split

# 1) 식별자 제거(과적합 방지) + 사후 플래그 5종 제거(누수 차단)
X = df.drop(columns=["UDI", "Product ID", "Machine failure", "TWF", "HDF", "PWF", "OSF", "RNF"])
y = df["Machine failure"]

# 2) 문자 등급(Type: L/M/H) → 숫자 표시로 변환(원핫 인코딩)
X = pd.get_dummies(X, columns=["Type"])
X = X[sorted(X.columns)]  # 열 순서 고정 — 누가 실행해도 같은 결과(재현성)

# 3) 층화 분할 — 학습 75% / 평가 25%, 양쪽 고장 비율을 똑같이 유지
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)

print(f"학습용: {X_train.shape[0]:,}건 (고장 {int(y_train.sum())}건, {y_train.mean()*100:.2f}%)")
print(f"평가용: {X_test.shape[0]:,}건 (고장 {int(y_test.sum())}건, {y_test.mean()*100:.2f}%)")
print(f"입력 변수 {X.shape[1]}개: {list(X.columns)}")

STEP 4 — 첫 모델: 정확도의 함정을 직접 봅니다¶

랜덤 포레스트 — 결정 나무 200그루의 다수결입니다. 설비 데이터 같은 표 데이터에서 가장 먼저 써 보는 방법입니다.

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import confusion_matrix, accuracy_score, recall_score, precision_score, f1_score

model = RandomForestClassifier(n_estimators=200, random_state=42, n_jobs=-1)
model.fit(X_train, y_train)          # 학습 — 약 5초
pred = model.predict(X_test)         # 평가용 2,500건 판정

acc = accuracy_score(y_test, pred)
rec = recall_score(y_test, pred)
prec = precision_score(y_test, pred)
f1 = f1_score(y_test, pred)
print(f"정확도 {acc*100:.1f}%  |  고장 재현율 {rec*100:.1f}%  |  고장 정밀도 {prec*100:.1f}%  |  F1 {f1:.3f}")

정확도 98.2%  |  고장 재현율 52.9%  |  고장 정밀도 88.2%  |  F1 0.662

# 혼동행렬 — 이 표를 읽을 줄 알면 절반은 끝났습니다
tn, fp, fn, tp = confusion_matrix(y_test, pred).ravel()

fig, ax = plt.subplots(figsize=(6.4, 4.6))

for r in range(2):
    for c in range(2):

                color="#C0392B" if (r, c) == (1, 0) else "#333")
ax.set_xticks([0.5, 1.5]); ax.set_xticklabels(["예측: 정상", "예측: 고장"], fontsize=11)
ax.set_yticks([0.5, 1.5]); ax.set_yticklabels(["실제: 고장", "실제: 정상"], fontsize=11)
ax.set_xlim(0, 2); ax.set_ylim(0, 2)
ax.set_title(f"정확도 {acc*100:.1f}% — 그런데 고장 {tp+fn}건 중 {fn}건을 놓쳤습니다", fontsize=13)
plt.tight_layout(); plt.show()
print(f"→ 놓친 고장(FN) {fn}건 = 전체 고장의 {fn/(tp+fn)*100:.1f}% 미감지")

여러분 화면의 숫자가 강의자료와 한두 건 다를 수 있습니다(실행 환경에 따른 차이). 숫자는 화면 기준으로 읽습니다.

# 처방 1) Class Weight — "고장을 틀리면 벌점을 크게" (코드 한 줄 추가)

STEP 6 — 기준선 옮기기: 모델은 그대로, 선만 바꿉니다¶

모델은 기록마다 "고장일 가능성"을 0~1 사이 숫자로 냅니다. 지금까지는 0.5를 넘으면 알람이었습니다. 이 기준선을 내리면 어떻게 될까요?

# 처방 없는 첫 모델을 그대로 두고, 기준선만 0.5 → 0.1 로 내려 봅니다
prob = model.predict_proba(X_test)[:, 1]          # 고장일 가능성 (0~1)
rows = []
for thr in [0.5, 0.4, 0.3, 0.2, 0.1]:
    t_n, f_p, f_n, t_p = confusion_matrix(y_test, (prob > thr).astype(int)).ravel()
    rows.append([thr, f_n, f_p, f"{t_p / (t_p + f_n) * 100:.1f}%"])
sweep = pd.DataFrame(rows, columns=["기준선", "놓친 고장", "헛경보", "재현율"])

기준선 = 0.3  #@param {type:"slider", min:0.05, max:0.95, step:0.05}
t_n, f_p, f_n, t_p = confusion_matrix(y_test, (prob > 기준선).astype(int)).ravel()
print(f"기준선 {기준선:.2f} → 고장 {t_p + f_n}건 중 {t_p}건 검출 · 놓친 고장 {f_n}건 · 헛경보 {f_p}건")

기준선 0.30 → 고장 85건 중 64건 검출 · 놓친 고장 21건 · 헛경보 21건

읽는 법 — 다시 학습하지 않았는데도 놓친 고장이 크게 줄었습니다. 기준선은 모델의 일부가 아니라 현장이 정하는 손잡이입니다. 놓침 한 건이 비쌀수록 기준선을 내리고, 헛경보가 부담일수록 올립니다.

import shap

explainer = shap.TreeExplainer(model)              # 베이스라인 모델의 속을 들여다봅니다
